Atur Pantau Pembangunan

Halaman ini hanya untuk direktur. Data yang sudah ada tidak akan diubah, hanya baris baru yang ditambahkan.

Panduan ambil data LPSE (baca dulu)

Persiapan

  1. Buka halaman Nontender atau Tender di LPSE: spse.inaproc.id/langkatkab/nontender atau spse.inaproc.id/langkatkab/lelang.
  2. Di bagian atas tabel, ubah Tampilkan menjadi 100.
  3. Kalau tampilan terlihat kecil, tekan Ctrl + 0 untuk mengembalikan zoom ke 100%.

Menjalankan skrip

  1. Pilih halaman yang ingin diambil, misalnya halaman 1 (paket 1 sampai 100).
  2. Tekan F12, lalu klik tab Console.
  3. Klik Salin skrip di bawah, lalu klik kolom Console dan tekan Ctrl + V, lalu Enter.
  4. Kalau muncul pesan "Don't paste code…", ketik allow pasting di kolom itu, tekan Enter, lalu tempel skrip sekali lagi.
  5. Tunggu sampai muncul tulisan Selesai. Setiap paket memakan sekitar 3 sampai 4 detik. Jangan tutup tab atau pindah halaman selama proses berjalan.
  6. File JSON akan terunduh otomatis, misalnya lpse-nontender-hal01.json, di folder Downloads.

Halaman berikutnya

  1. Kembali ke daftar LPSE, pilih halaman berikutnya, misalnya halaman 2.
  2. Ulangi langkah Console di atas. Nama file mengikuti nomor halaman secara otomatis.

Mengirim hasilnya

  1. Kirim semua file JSON ke asisten untuk digabungkan. Jangan diunggah di halaman ini dulu.
  2. Jika ada pesan Gagal di Console, catat kode paketnya dan kirim juga.
